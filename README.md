# 🛡️ SIPRE - Sistema Insurtech de Protección por Remesas

> **Plataforma de Microseguros Dinámicos Embebidos en Flujos de Remesas**  
> Desarrollado por **Ing. Gustavo Rodríguez**

---

## 📌 Descripción del Proyecto

**SIPRE** es una solución arquitectónica e implementación de referencia diseñada para cerrar la brecha de asegurabilidad en Venezuela y Latinoamérica. Permite activar micropólizas de salud y emergencias médicas de corta duración (30 días) disparadas de forma automática al momento de procesar una remesa.

## 🛠️ Stack Tecnológico

* **Frontend Móvil:** [Flutter](https://flutter.dev/) (Multiplataforma iOS/Android).
* **Backend REST:** [Delphi](https://www.embarcadero.com/products/delphi) + [Horse Framework](https://github.com/HashLoad/horse) (Microservicios de alto rendimiento compilados a código nativo).
* **Base de Datos:** [PostgreSQL](https://www.postgresql.org/) (Transacciones ACID y lógica almacenada para reglas de seguros).
